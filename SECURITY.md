# Security Policy

Security fixes are made on the latest `main` branch.

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/jaintarun/agent-history/security/advisories/new).
Do not include credentials, API keys, private transcripts, database files, or
other personal data in a public issue.

Agent History reads local AI-session transcripts and sends normalized visible
conversation to the CLI provider selected by the user. Review the privacy
section in `README.md` before enabling automatic analysis.
